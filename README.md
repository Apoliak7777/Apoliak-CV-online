# Apoliak CV online

Osobné portfólio a online životopis. Statická stránka — HTML, CSS, JavaScript, bez frameworku.

Dvojjazyčná verzia SK / EN. Texty a dáta sú v `content.js`, zvyšok v `index.html`. Pri zdieľaní linku sa použije `og-image.svg`.

Sekcie: skúsenosti, projekty, schopnosti, vzdelanie, certifikáty.
